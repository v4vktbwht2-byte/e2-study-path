# License, Content, and Branding Rules

## Branding

- `E2 Study Path` is a working title.
- The application must state that it is unofficial and not endorsed by the Eiken Foundation of Japan.
- Do not use official logos, seals, score reports, or designs that imply affiliation.
- Avoid product names that include wording such as “official,” “authorized,” or “certified.”

## Educational content

- Do not copy official past questions, listening audio, answer sheets, textbook passages, or commercial vocabulary-book entries.
- It is acceptable to model high-level task types, timings, and word-count constraints while creating fully original prompts, passages, distractors, examples, and explanations.
- Every content record should include provenance metadata such as `source.type: "original"`.
- Content generated by an AI agent must be reviewed with `checklists/CONTENT_QA.md` before release.

## Software license

Codex should add a software license only after the repository owner chooses one. Until then, do not assume the project is open source.

## Assets

- Use self-created SVG icons, openly licensed icons, or installed icon libraries with compatible licenses.
- Record third-party notices when required.
- Do not bundle font files unless their license and redistribution terms are explicitly verified. Prefer system fonts.
