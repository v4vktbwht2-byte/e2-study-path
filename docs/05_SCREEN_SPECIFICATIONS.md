# 05. Screen Specifications

## 1. 共通レイアウト

- モバイルファースト
- 最大コンテンツ幅: 960px前後
- 下部ナビゲーションはセーフエリアを考慮
- 学習中はナビゲーションを簡略化し集中を優先
- 主要ボタンは画面下部に届きやすく配置
- 44×44 CSS px以上のタップ領域

## 2. オンボーディング

### 2.1 Welcome

表示:

- アプリの目的
- 「初心者から始められる」
- 「学習データはこの端末に保存」
- 非公式アプリの注記
- 開始ボタン

### 2.2 Goal Setup

入力:

- 学習目標
- 1日の学習時間
- 受験予定日（任意）
- 通知案内は初期版では設定説明のみ

### 2.3 Diagnostic Intro

- 所要時間の目安
- 分からない問題は飛ばせる
- 点数で責めない説明
- 診断する／あとで

## 3. 診断画面

構成:

- 進捗: 「8 / 最大24」など上限を示す
- 問題文
- 選択肢または入力
- 音声問題では明確な再生ボタン
- 「分からない」
- 次へ

結果画面:

```text
おすすめ開始地点
ステージ1：英語の1文を作る

すでにできていること
・アルファベット
・基本的なあいさつ

最初に学ぶこと
・am / is / are
・一般動詞
・疑問文
```

## 4. 今日画面

カード:

- 今日のおすすめ
- 復習期限
- 続きから
- 単語集中ショートカット
- 今週の重点

状態例:

- 初回でプランなし
- すべて完了
- 復習が大量
- オフライン
- コンテンツ読み込み失敗

## 5. コースマップ

- ステージを縦方向のカードまたはリストで表示
- 現在地を明確化
- 各ステージに概要、完了率、次のレッスン
- ロックアイコンより「推奨順」を使い、強制感を減らす

## 6. レッスン画面

### セクション

1. 目標
2. 説明
3. 例文
4. 確認
5. 思い出す
6. 使ってみる
7. まとめ

### 操作

- 前へ／次へ
- ヒント
- 音声
- お気に入り
- 中断

### フィードバック

誤答時:

- 正答
- なぜそうなるか
- 間違えやすい点
- もう一度

単なる赤い×だけにしない。

## 7. 単語ハブ

上部:

- 今日の復習件数
- 新規上限
- 学習時間見積もり

メニュー:

- 復習を始める
- 新しい単語10語
- 苦手だけ
- 5分高速チェック
- 聞き取り
- スペル
- 単語一覧

フィルター:

- ステージ
- 品詞
- 学習状態
- お気に入り
- タグ

## 8. 単語学習カード

表面:

- 英単語または日本語
- 発音ボタン
- 「思い出した」後に答えを表示

裏面:

- 意味
- 品詞
- 短い例文
- 例文訳
- 関連表現
- Again / Hard / Good / Easy

最初から答えを見せる閲覧モードと、答えを隠すテストモードを明確に分ける。

## 9. 単語詳細

- 見出し語
- 発音
- 意味別カード
- 例文
- コロケーション
- 類義・反意・混同語
- 自分のメモ
- 習熟度5軸
- 次回復習
- 過去の回答履歴
- 復習をリセット／一時停止

## 10. 復習セッション

上部:

- 残り件数
- 経過時間
- セッション終了ボタン

中央:

- 問題
- 回答欄
- ヒント

回答後:

- 正誤
- 解説
- 推奨評価
- 4段階評価
- 次回予定の簡易表示

## 11. 読解

- 本文の文字サイズ変更
- 段落番号
- 設問
- 回答後の根拠ハイライト
- 重要語句を単語帳へ追加
- 読了・回答時間

## 12. リスニング

本番風:

- 1回再生
- スクリプト非表示
- 再生前に確認

復習:

- 0.75 / 1.0 / 1.25倍
- 一文ずつ
- スクリプト
- ディクテーション
- シャドーイング用リピート

音声がない場合:

- Web Speechが利用可能なら読み上げ
- 非対応ならスクリプト学習へ切替
- 無音のままボタンだけ置かない

## 13. ライティング

### 要約

- 原文
- メモ欄
- 45〜55語の範囲表示
- 語数カウンター
- 自己確認
- 保存

### 意見英作文

- Topic
- Points
- 構成メモ
- 80〜100語カウンター
- 自己評価4観点
- 保存

## 14. スピーキング

- 録音対応状況
- マイク権限説明
- タイマー
- 問題カード風のオリジナル画面
- 録音開始・停止
- 再生
- 自己評価
- 削除

権限拒否時は、回答テキスト入力と模範構成の確認へ切り替える。

## 15. 記録

- 今週の学習時間
- 復習した項目
- 新規項目
- 技能別傾向
- ステージ進行
- 苦手上位
- 7日／30日切替

グラフには必ずテキスト要約を併記する。

## 16. 設定・データ

- 1日の学習時間
- 新規単語上限
- 目標復習保持率のプリセット
- 音声速度
- テーマ
- 文字サイズ
- 動きの軽減
- バックアップ
- 復元
- キャッシュ削除
- 全データ削除
- アプリ情報・非公式注記
