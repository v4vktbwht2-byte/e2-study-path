# 01. Scope and Releases

## 1. リリース区分

### Pilot Release — Phase 00〜10

機能の縦断動作を完成させ、実際に自己学習できる状態にする。教材は全フローを試せる量を収録するが、商用教材集ほどの網羅量は要求しない。

### Content Expansion — Phase 11

スキーマと検証基盤を使い、教材を段階別に増やす。アプリコードと教材制作を分離する。

### Optional AI Release

サーバー側APIを追加できる場合に限り、作文添削や会話フィードバックを追加する。コアリリースの完成条件には含めない。

## 2. Pilot Releaseの必須範囲

### プロダクト

- 初回オンボーディング
- 目標・学習時間設定
- 初期診断
- ステージ0〜6のコースマップ
- 今日の学習自動編成
- レッスンエンジン
- 単語集中モード
- 復習スケジューラー
- 復習滞留時の軽量化
- 技能別練習
- 学習記録・弱点分析
- 設定
- バックアップ・復元

### PWA

- Manifest
- Service Worker
- インストール案内
- アプリシェルのオフライン起動
- 基本教材のオフライン利用
- オフライン状態表示
- 更新検知と安全な更新UI
- 保存容量と音声キャッシュ管理

### 品質

- 型安全
- コンテンツスキーマ検証
- 単体テスト
- コンポーネントテスト
- E2Eテスト
- アクセシビリティ確認
- CI
- 静的ホスティング用ビルド

## 3. Pilot Releaseの教材最低数

| 種別 | 最低数 | 備考 |
|---|---:|---|
| 単語・熟語 | 140 | 各ステージ20件以上を目安 |
| レッスン | 14 | 各ステージ2件以上 |
| 文法・語彙演習 | 80 | 複数形式を含む |
| 読解 | 6セット | 初級〜2級準備 |
| リスニング | 6セット | スクリプト必須 |
| 英文要約 | 4題 | 上位ステージ向け |
| 意見英作文 | 4題 | 理由2つを練習 |
| スピーキング | 4セット | 録音・自己評価 |
| 短縮模擬演習 | 1セット | 全技能の一部 |

教材はすべてオリジナルとし、`source.type = "original"` を持つ。

## 4. Pilot Releaseから除外するもの

- ユーザーアカウント
- 複数端末同期
- サーバーデータベース
- Push通知の必須化
- 決済
- 広告
- 学校管理者機能
- 公式過去問の収録
- 大量の音声ファイル自動生成
- AI APIキーをブラウザーへ入力させる設計
- 発音の自動採点を公式評価として表示すること

## 5. 将来の拡張余地

- クラウド同期
- 複数プロフィール
- 学習計画のカレンダー連携
- 追加コンテンツパック
- 音声パックの選択ダウンロード
- AI作文添削
- 音声認識による会話練習
- 教師用エクスポート
- 多言語UI

## 6. スコープ変更のルール

Codexが実装中に「便利そう」という理由だけで機能を追加してはならない。新しい本番依存関係または大きな機能を追加する場合は、次を `docs/19_DECISIONS_AND_OPEN_POINTS.md` に記録する。

- 追加理由
- 既存仕様で代替できない理由
- 保守コスト
- オフラインへの影響
- テスト方法
