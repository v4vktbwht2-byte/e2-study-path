# Content QA Checklist

## All content

- [ ] stable unique ID
- [ ] schemaVersion / contentVersion
- [ ] stage and prerequisites
- [ ] source.type = original
- [ ] official question/audio/logoを使用していない
- [ ] spelling and grammar checked
- [ ] Japanese is natural
- [ ] no unsafe raw HTML
- [ ] answer is unambiguous
- [ ] explanation actually explains why
- [ ] target skills and mastery dimensions are correct

## Vocabulary

- [ ] lemma/headword correct
- [ ] part of speech correct
- [ ] meaning matches example
- [ ] example translation matches
- [ ] lower-stage example is not too difficult
- [ ] collocation is natural
- [ ] sense is not overloaded
- [ ] confusion group is accurate
- [ ] pronunciation data verified or omitted

## Multiple choice

- [ ] exactly intended number of choices
- [ ] answer index valid
- [ ] no duplicate choices
- [ ] distractors are plausible but clearly wrong
- [ ] no second valid answer

## Reading

- [ ] passage structure is coherent
- [ ] evidence reference exists
- [ ] answer is supported by text
- [ ] distractor explanations are valid
- [ ] passage does not depend on unstable current facts without sourcing

## Listening

- [ ] script complete
- [ ] speaker labels
- [ ] question can be answered from audio
- [ ] audio strategy defined
- [ ] fallback works

## Writing

- [ ] prompt allows more than one defensible answer
- [ ] summary key points defined
- [ ] sample word count valid
- [ ] opinion points are optional hints, not forced answers
- [ ] rubric is present

## Speaking

- [ ] passage length appropriate
- [ ] No.1 evidence defined
- [ ] three scenes have clear sequence
- [ ] opinion questions are answerable
- [ ] sample responses are examples, not sole answers

## Batch report

- [ ] validation command pass
- [ ] duplicate report
- [ ] stage coverage report
- [ ] human spot-check list
